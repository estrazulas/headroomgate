First time? Generate an admin key

Option A — Manual CLI (server terminal):

headroom auth init-db \
  && headroom auth create-user admin --role admin --team ops \
  && headroom auth create-key admin

Initializes the DB, creates an admin user, and prints an hr_ key.

Option B — Automated installer:

git clone https://github.com/estrazulas/deepclaude_with_headroom.git \
  && cd deepclaude_with_headroom \
  && bash install.sh

Runs an interactive wizard that installs the proxy, initializes auth, and generates the first admin key automatically. See install docs →
